# 学段适配指南

> 同一套内核，不同年龄**执行方式必须不同**。
> 本文档是"总纲 → 具体孩子"的翻译层。

---

## 通用原则：家长角色必须"往后退"

```
小学低段  ──家长是【陪玩者】──  一起做，把学习藏进游戏
小学高段  ──家长是【教练】────  教流程，不给答案
初中      ──家长是【管理者】──  管节奏，不管内容
高中      ──家长是【后勤】────  提供条件，不介入方法
```

> ⚠️ **家庭学习冲突的第一大来源**：
> 孩子已经长大了，家长还用上一个学段的方式管。
> 判断标准很简单——**如果孩子的反应是"烦"，通常不是态度问题，是角色错位。**

---

## 一、小学低段（1-3 年级，6-9 岁）

### 这个阶段的核心任务
**不是"学会知识"，是"爱上学习"和"建立基本习惯"。**
这个阶段逼成绩，是本末倒置。

### 认知特点
- 注意力时长：**10-15 分钟**（超过必然走神，不是孩子的错）
- 抽象思维未发展 → **必须具象、可触摸、可看见**
- 极度依赖即时反馈和情绪体验 → **学习体验 = 情绪体验**

### 四动作怎么落地

| 动作 | 低段做法 | 例子 |
|---|---|---|
| ①编码 | **多感官 + 故事化** | 认字：用身体摆字形；算术：用积木/糖果 |
| ②巩固 | **游戏化短时高频** | 每天 5 分钟卡片游戏，而不是 30 分钟抄写 |
| ③提取 | **口头问答，不写字** | "小熊有几个苹果？"而不是做卷子 |
| ④迁移 | **生活场景套用** | 超市算钱、分蛋糕学分数 |

### 家长具体动作（可照抄）
```
✅ 这样说：
  「我们来玩个游戏，看谁先找到 3 个圆的东西！」
  「你当小老师，教妈妈这个字怎么记？」
  「哇，你是怎么想到的？」（问过程，不问结果）

❌ 不要这样说：
  「这么简单都不会？」
  「你看隔壁小明……」
  「快点写，写完了才能玩。」（把玩变成贿赂）
```

### 每日节奏（低段）
```
放学 → 吃点心+自由玩 30 分钟（必须有，不是奖励）
     → 作业 15-20 分钟（可分 2 段，中间休息）
     → 亲子阅读 15 分钟（孩子读或家长读，纯享受，不提问考）
     → 睡前 5 分钟口头复习（当游戏，不当任务）
```

### 这个阶段的危险信号
- 孩子开始说"我笨" → **立刻停止一切成绩导向的施压**
- 写作业拖到很晚 → 通常是**任务量超出注意力容量**，要拆小
- 家长每天吼 → 说明家长的方法（不是孩子）需要换

## 二、小学高段（4-6 年级，9-12 岁）

### 这个阶段的核心任务
**从"被带着学"过渡到"自己会学"。**
这是整个 K12 最关键的**方法窗口期**——
此时建立的习惯，能一路用到高考；错过的，初中要花双倍力气补。

### 认知特点
- 注意力：**20-30 分钟**
- 开始能理解抽象概念，但需要具体例子支撑
- **开始在意同伴评价** → 可以用"讲给同学听"驱动
- 自我意识觉醒 → **命令式管教会引发对抗**

### 四动作怎么落地

| 动作 | 高段做法 |
|---|---|
| ①编码 | 要求**"讲出为什么"**；开始做简单的概念图 |
| ②巩固 | **引入日程化的间隔复习**（这是本阶段最重要的新增） |
| ③提取 | **开始用自测本 / 卡片**；错题本正式启用 |
| ④迁移 | **一题多解启蒙**；"如果条件变一下会怎样" |

### 关键新增工具：间隔复习表
```
做一个纸质表格贴在书桌前（或用 PWA）：

科目/知识点 | 当天 | D2 | D4 | D7 | D15 | D30
─────────────────────────────────────────
古诗《XX》   |  ✅  |    |    |    |     |
分数加减     |  ✅  | ✅ |    |    |     |
```

> 这一步是**分水岭**。做到的孩子，初中会明显轻松；
> 没做到的，初中会陷入"天天在补昨天的账"。

### 家长具体动作
```
✅ 从"检查答案"转向"检查流程"：
  「今天复习表上的都打勾了吗？」
  「这道错题，你当时是怎么想的？」
  「你觉得这次错在哪一类？」

✅ 开始放手：
  让孩子自己定计划（哪怕定得不好），家长只问"需要我帮什么"
```

### 这个阶段的危险信号
- 孩子说"反正我怎么做都不对" → 家长介入过多
- 复习表连续一周空白 → 流程太重，要减到能坚持为止
- 开始撒谎说"写完了" → 通常是**任务量 vs 能力**失衡，要重新评估

## 三、初中（7-9 年级，12-15 岁）

### 这个阶段的核心任务
**从"会学"到"自主管理"，并扛住知识量激增。**

初中知识量约为小学的 3 倍，且抽象度陡增。
**小学靠"聪明+听话"能混过去的，初中会集体失灵。** 这是第一个大分化点。

### 认知特点
- 抽象思维成熟，可以处理假设性、系统性内容
- **前额叶未发育完** → 计划能力、自控力生理性不足（不是态度问题！）
- 同伴影响 > 家长影响 → 硬管会推向对立面
- 需要**自主感**（自我决定理论：自主/胜任/归属）

### 四动作怎么落地

| 动作 | 初中做法 |
|---|---|
| ①编码 | **结构化笔记**（概念图、康奈尔笔记）；强调知识间的联系 |
| ②巩固 | **系统化错题本 + 长周期间隔复习** |
| ③提取 | **限时自测、模拟考**；真题驱动 |
| ④迁移 | **跨章节综合题、变式训练** |

### 本阶段最重要的一件事：教"计划"，而不是"催"
```
❌ 「你今天作业写完了吗？」（催）
✅ 「这周的复习你打算怎么排？」（教计划）
```

**教计划的脚手架（家长只问，不替做）**：
```
1. 「这周有几件事要完成？列出来。」（任务分解）
2. 「哪件最难？难的放什么时候做？」（优先级 + 精力管理）
3. 「上次的计划哪儿没完成？这次怎么调？」（复盘迭代）
```
> 孩子计划做得好不好不重要，**做了 20 次之后自然会好**。
> 家长替做 100 次，孩子永远学不会。

### 关于"沉迷手机"
> 不要用"没收"解决，那是把问题变成战争。
> 有效的做法只有两条：**① 环境设计 ② 替代满足**
> - 环境设计：学习时手机放在另一个房间（不是"放桌上但别看"）
> - 替代满足：孩子沉迷的往往不是手机，是**成就感/社交/逃避**
>   查清楚是哪一种，比没收手机有用得多。

### 这个阶段的危险信号
- 成绩突然下滑 → **先查睡眠和情绪，再查方法**（多数不是"不努力"）
- 拒绝沟通 → 关系出问题了，此时任何方法都推不进去，**先修关系**
- 熬夜学习 → 效率极低且伤身，**睡眠是学习的一部分，不是对立的**

## 四、高中（10-12 年级，15-18 岁）

### 这个阶段的核心任务
**自主建构知识网络 + 精准定位薄弱点 + 扛住长周期压力。**

### 认知特点
- 接近成人认知能力
- 自主需求极强 → **家长介入方法= 冒犯**
- 时间极度稀缺 → **任何方法必须"省时间"，不能"增加任务"**

### 四动作怎么落地
| 动作 | 高中做法 |
|---|---|
| ①编码 | 自主建构知识网络；跨学科联系 |
| ②巩固 | 长周期规划 + 高频回顾（周循环） |
| ③提取 | **真题驱动**、限时训练、精准定位薄弱 |
| ④迁移 | 迁移到新题型、新情境 |

### 家长在这个阶段唯一该做的事
```
✅ 后勤：睡眠、饮食、情绪、减少干扰
✅ 资源：需要什么资料/课，提供条件
✅ 信任：不查岗、不比较、不追问排名

❌ 绝对不要：
  · 介入学习方法（他自己比你懂他的学习）
  · 用"我们为你付出这么多"施压
  · 在考砸时讲道理（此时只需要："辛苦了，先吃饭"）
```

### 关于压力
```
健康压力 ──→ 促进表现
过度压力 ──→ 认知资源被情绪占用，成绩反而下降
```
**家长的情绪稳定，是孩子最重要的备考资源。**

## 五、多孩家庭：最容易翻车的地方

你家里有几个孩子，这一节可能是**最关键的**。

### 三大陷阱

#### 陷阱 1：用同一套标准要求不同年龄的孩子
```
❌ 「你看你哥，三年级就能自己写作业了！」
→ 结果：小的自卑，大的压力，两人关系恶化
```
✅ **正确做法**：每个孩子有**独立的进度表**，
   只跟"他自己的上个月"比。

#### 陷阱 2：大孩子被迫当"小老师"
```
适度：偶尔讲题 → 双方受益（讲的人收获最大）
过度：每天辅导弟妹 → 大孩子时间被侵占，产生怨恨
```
✅ 规则：**辅导弟妹必须自愿，且 ≤ 每周 2 次、每次 ≤ 20 分钟。**

#### 陷阱 3：资源向"有希望"的孩子倾斜
```
家长往往无意识地：成绩好的投入多，成绩差的放弃。
→ 这恰恰是"教育不平等"在家庭内部的复制。
```
✅ **反向原则**：越困难的孩子，越需要方法支持（而不是更多压力）。

### 多孩家庭的操作建议
1. **错峰陪伴**：每天给每个孩子 **10 分钟专属时间**（不能合并）
   —— 质量远比时长重要，10 分钟专注 > 2 小时心不在焉
2. **共用流程，不共用进度**：复习表模板相同，内容各自填
3. **公开规则，私下反馈**：规则全家一致；批评单独说，不当众比较
4. **让大孩子参与"教方法"**，而不是"教知识"
   —— 比如让哥哥帮弟弟**检查复习表打勾了没**（不负责讲题）

## 六、一页速查表

| 学段 | 核心任务 | 家长角色 | 最重要的一件事 | 最大禁忌 |
|---|---|---|---|---|
| 1-3年级 | 爱上学习 | 陪玩者 | 把学习变游戏 | 逼成绩 |
| 4-6年级 | 学会方法 | 教练 | **建立间隔复习习惯** | 只查答案 |
| 初中 | 自主管理 | 管理者 | **教计划而非催促** | 硬管手机 |
| 高中 | 自主建构 | 后勤 | 情绪稳定 | 介入方法 |
