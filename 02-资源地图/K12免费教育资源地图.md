# K-12 教育平权 · 免费优质资源地图（中国大陆家庭可用版）

> **适用场景**：中国家长，孩子 1–12 年级，iPad 设备，离线/低带宽优先，合法使用与合法链接。
> **编制日期**：2025年（URL 于编制时逐条 HTTP 探测，见每条"可信度"说明）
> **可信度评级说明**：
> - ★★★★★ = 官方/权威机构主办 + URL 实测可达 + 授权清晰
> - ★★★★ = 成熟机构 + URL 实测可达，可能有登录/带宽限制
> - ★★★ = 可用但存在明确短板（需 VPN / 需注册 / 维护不稳 / 中文不全）
> - ★★ = 曾广泛流传但**本次未能验证**或已出现停运/失效迹象 → 不建议作为项目主力

**「能否离线」含义**：✅ 可下载后完全离线使用；⚠️ 需联网但可缓存/低带宽可接受；❌ 必须在线。
**「国内直连」含义**：✅ 无需 VPN；⚠️ 时好时坏；❌ 需梯子。
