# PhET 中文可离线模拟清单（HTML5 版）

> 数据来源：PhET 官方元数据 API（含官方学科分类表），实测于 2026-10-16。
> 共 **189 个** HTML5 中文模拟，已排除 44 个无法在平板运行的遗留 Java 版。
> 授权 **CC BY 4.0** —— 可自由再分发、可离线、免费。

## 怎么用（3 步）

1. 在下表找到要用的模拟，记下它的**英文名**
2. 按下面格式拼成直链
3. 在 iPad Safari 打开即用 → 分享 → 「添加到主屏幕」→ 断网也能用

```
https://phet.colorado.edu/sims/html/<英文名>/latest/<英文名>_zh_CN.html
```

> 例：四则运算 → https://phet.colorado.edu/sims/html/arithmetic/latest/arithmetic_zh_CN.html
> （已实测返回 200，页面标题正确显示「四则运算」）
