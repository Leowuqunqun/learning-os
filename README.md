# 学习操作系统 · 教育平权项目

> **把好学校里那套隐性的学习方法，写下来，给每一个家庭。**
>
> 免费 · 离线可用 · 低配设备可用 · 数据自主 · 不需要家长会做题

---

## 这是什么

一套给 K12 家庭的**学习方法论 + 工具**。核心主张：

> 教育不平等最致命的不是资源不平等，而是**方法不平等**——
> 优势家庭靠家长"隐性传授"学习方法，劣势家庭没人教。
> **而隐性知识是可以被写下来、被复制的。**

所以这套东西的每个动作，都遵守一个判据：
**把动作简化到"最没条件的家庭也能做"。**

## 核心框架：学习只有 4 个动作

| 动作 | 做什么 | 为什么有效 |
|---|---|---|
| **① 编码** | 合上书，用自己的话讲一遍 | 放弃"重读"（证据评级最低），改用自我解释 |
| **② 巩固** | 按间隔表自测：当天→D2→D4→D7→D15→D30 | 间隔效应（强证据；但精确天数在儿童身上证据薄弱） |
| **③ 提取** | 错题重做、讲给别人听 | 测试效应：g≈0.51（对比重读） |
| **④ 迁移** | 变式练习，至少 2 个不同表面的例子 | 迁移需要多个例子（Gick & Holyoak 1983） |

## 证据基础（诚实版）

本项目的核心主张建立在**高证据强度**的发现上：

✅ **强证据**
- 提取练习（自测）优于重读 —— 两项元分析一致，Adesope 2017 总体 g=0.61
- 间隔练习优于集中练习 —— 184 篇文献综合
- 语音意识+拼读（低龄）—— 高危儿童回报最高（随访 d=1.33）
- 工作示例对新手有效 —— 但**必须随专长逆转**

⚠️ **有争议 / 被夸大（本项目不夸大）**
- **交错练习**：元分析显示数学仅 g=0.34（小效应），说明文不显著，
  **词汇学习反而"集中练"更好（g=−0.39）**
  → 所以本项目：数学/理科用交错，**背单词不用**
- **成长型思维**：63 项研究 N=97,672，d̄=0.05，**发表偏倚校正后不显著**
  → 所以本项目**不宣称"成长型思维能提分"**
- **儿童的最优间隔参数**：经典研究多为大学生，
  真实小学课堂研究显示"间隔的额外收益不显著"
  → 所以本项目给的是保守排程，**不宣称某个天数有魔力**

❌ **明确证伪（本项目绝不使用）**
- 学习风格匹配（视觉型/听觉型）
- 左右脑 / 右脑开发
- "关键期过了就学不会"
- 脑力训练的迁移效应
- 学习金字塔百分比（10%/20%/90%）—— 数字是编造的
- SQ3R"有科学依据"（实际缺乏严格实验支持）

> 完整论证见 [`学习科学证据简报.md`](01-方法论/学习科学证据简报.md) §8、§9。

## 设计红线（违反任一条就不做）

1. **零成本** —— 核心方法必须免费，付费只能是可选增强
2. **离线可用** —— 断网后核心功能不失效
3. **低配可用** —— 老旧设备能跑（当前：单文件 20KB，零外部依赖）
4. **低文化门槛** —— 不假设家长学历
5. **数据自主** —— 学习数据默认只存本地，不上传（涉及未成年人）
6. **可复制** —— 一个家庭跑通后能整体复制给另一个家庭
