学习操作系统 · 教育平权项目

把好学校里那套隐性的学习方法，写下来，给每一个家庭。

免费 · 离线可用 · 低配设备可用 · 数据自主 · 不需要家长会做题

这是什么

一套给 K12 家庭的学习方法论 + 工具。核心主张：

教育不平等最致命的不是资源不平等，而是方法不平等—— 优势家庭靠家长"隐性传授"学习方法，劣势家庭没人教。 而隐性知识是可以被写下来、被复制的。

所以这套东西的每个动作，都遵守一个判据： 把动作简化到"最没条件的家庭也能做"。

快速开始

1. 完全没条件？先看这个（0 元，5 分钟）

打开 01-方法论/打印版-零门槛.html → 点「打印」（电脑 Ctrl+P / Mac ⌘P，手机在分享菜单）→ 打 3 页 → 贴上冰箱。 只需要纸和笔，爷爷奶奶也能执行。

2. 有手机/平板？直接打开（无需安装）

线上地址（直接发给家长即可）： https://leowuqunqun.github.io/learning-os/

装到桌面，就像 App 一样用，断网也能用：

设备 怎么装
iPhone / iPad用 Safari 打开 → 底部「分享」→「添加到主屏幕」
安卓手机 / 平板用 Chrome 打开 → 右上角「⋮」→「安装应用」或「添加到主屏幕」
电脑直接打开即可，也可以拖到书签栏

注意：iOS 上必须用 Safari（用微信内置浏览器打开的话， 请点右上角「⋯」→「在 Safari 中打开」，否则装不了）。 安卓用 Chrome 同理。

如果你想自己部署一份（技术用户）

cd 03-PWA && python3 -m http.server 8080
# 浏览器打开 http://localhost:8080

或直接把 03-PWA/ 目录放到任意静态托管（GitHub Pages / Cloudflare Pages 都免费）。 整个应用 88KB、零依赖，不需要后端。

核心框架：学习只有 4 个动作

动作 做什么 为什么有效
① 编码合上书，用自己的话讲一遍放弃"重读"（证据评级最低），改用自我解释
② 巩固按间隔表自测：当天→D2→D4→D7→D15→D30间隔效应（强证据；但精确天数在儿童身上证据薄弱）
③ 提取错题重做、讲给别人听测试效应：g≈0.51（对比重读）
④ 迁移变式练习，至少 2 个不同表面的例子迁移需要多个例子（Gick & Holyoak 1983）

证据基础（诚实版）

本项目的核心主张建立在高证据强度的发现上：

✅ 强证据

  • 提取练习（自测）优于重读 —— 两项元分析一致，Adesope 2017 总体 g=0.61
  • 间隔练习优于集中练习 —— 184 篇文献综合
  • 语音意识+拼读（低龄）—— 高危儿童回报最高（随访 d=1.33）
  • 工作示例对新手有效 —— 但必须随专长逆转

⚠️ 有争议 / 被夸大（本项目不夸大）

  • 交错练习：元分析显示数学仅 g=0.34（小效应），说明文不显著， 词汇学习反而"集中练"更好（g=−0.39） → 所以本项目：数学/理科用交错，背单词不用
  • 成长型思维：63 项研究 N=97,672，d̄=0.05，发表偏倚校正后不显著 → 所以本项目不宣称"成长型思维能提分"
  • 儿童的最优间隔参数：经典研究多为大学生， 真实小学课堂研究显示"间隔的额外收益不显著" → 所以本项目给的是保守排程，不宣称某个天数有魔力

❌ 明确证伪（本项目绝不使用）

  • 学习风格匹配（视觉型/听觉型）
  • 左右脑 / 右脑开发
  • "关键期过了就学不会"
  • 脑力训练的迁移效应
  • 学习金字塔百分比（10%/20%/90%）—— 数字是编造的
  • SQ3R"有科学依据"（实际缺乏严格实验支持）

完整论证见 学习科学证据简报.md §8、§9。

资源地图要点（已实测）

  • PhET 互动模拟：189 个中文 HTML5 模拟，CC BY 4.0（授权最干净） → 可自由打包、可离线、免费。直链格式见清单文件。
  • 国家中小学智慧教育平台：主力免费平台，电子课本可下载 ⚠️ 但版权属出版社 → 项目只能引导家长自行下载，不得打包再分发
  • ⚠️ "Khan Academy 有完整中文版"是错的 —— 域名存活但内容严重不全
  • ⚠️ Anki iOS 版收费（约 $24.99） —— iPad 用户请走网页版 ankiweb.net
  • ⚠️ 一批网上高频推荐的站点实测已失效（51voa/putclub/hxen/24en 等），清单内已标注

设计红线（违反任一条就不做）

  1. 零成本 —— 核心方法必须免费，付费只能是可选增强
  2. 离线可用 —— 断网后核心功能不失效
  3. 低配可用 —— 老旧设备能跑（当前：整体 88KB / 4 个模块，零外部依赖； 已实测模拟旧安卓环境，见 tools/test-safari.py 第 6 节）
  4. 低文化门槛 —— 不假设家长学历
  5. 数据自主 —— 学习数据默认只存本地，不上传（涉及未成年人）
  6. 可复制 —— 一个家庭跑通后能整体复制给另一个家庭
