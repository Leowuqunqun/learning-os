学习操作系统（Learning OS）总纲

一句话：把"学习"从一种天赋，变成一套可以照着做的流程。

教育平权的本质不是"给穷孩子也发一台 iPad"， 而是把好学校里那套隐性的学习方法显性化、流程化、工具化， 让任何一个家长——哪怕自己没读过多少书——都能照着执行。

0. 这套东西要解决什么

你列出的 7 个痛点，其实不是 7 个问题，而是 3 个层次的问题：

层次 你的痛点 真正的问题
动力层不会自主规划、靠催；沉迷手机、注意力差孩子没有"我为什么要学"的内在理由，且环境默认奖励分心
方法层不会读书、阅读理解差；数学不会举一反三；作文写不出、英语没兴趣没有人教过"具体怎么做"，孩子只会最笨但最省力的方法（反复读、抄写）
支持层家长不知道怎么辅导、没时间陪家长被要求扮演"老师"角色，但这个角色既没培训、也没时间

大多数家庭教育产品只解决"支持层"（给家长一堆课），结果家长更焦虑。 必须先解决方法层——因为方法层一旦跑通，孩子自己能看到进步，动力层会自动改善， 家长也才真正"没时间陪也没关系"。

所以本方案的顺序是：方法层 → 动力层 → 支持层。

1. 第一性原理：学习只有 4 个动作

抛开所有花哨理论，任何一次有效的学习，拆到底只有 4 个动作。 我把它叫做 学习操作系统的最小内核：

① 编码 Encode   —— 把新东西真正装进脑子（不是"看过"，是"懂了"）
② 巩固 Consolidate —— 跟遗忘做对抗（不是"再读一遍"，是"想起来"）
③ 提取 Retrieve  —— 在需要的时候能拿出来用（不是"我学过"，是"我会用"）
④ 迁移 Transfer  —— 换个场景还能用（这才是"举一反三"）

每一个动作，都有一个"人的本能做法"和一个"科学做法"。
差距就出在这里 ↓
动作 本能做法（低效，但舒服） 科学做法（费力，但有效） 关键机制
① 编码反复读、划重点、抄笔记合上书自己讲一遍；问"为什么"精细加工 / 自我解释
② 巩固考前突击、连续刷同一类题间隔复习、打乱顺序混着练 ※间隔效应 / 交错练习
③ 提取看着书觉得"我会了"合上书默写、自测、讲给别人听提取练习 / 测试效应
④ 迁移同一题型刷 100 遍变式练习、跨情境应用变异理论 / 图式建构

※ 关于"混着练"（交错练习），证据比网上说的小： 元分析显示数学只有小效应，说明文不显著，而背单词反而是集中练更好。 所以：数学和理科可以混着练，背单词不要。 详见 学习科学证据简报.md §3。

※ 关于"间隔复习"：「间隔优于集中」是强证据；但具体隔几天在儿童身上 证据薄弱（经典研究多为大学生）。照表做是安全的，但别把天数当成精确公式。

整个方法论体系，就是围绕这 4 个动作设计的。 后面所有工具、卡片、流程，都能映射回这 4 个动作之一。 如果一个工具说不清它服务于哪个动作，它就是多余的。

2. 为什么"本能做法"如此顽固

因为本能做法让大脑感觉更好。

  • 反复阅读 → 越读越顺 → 大脑判断"我掌握了" → 流畅性错觉（fluency illusion）
  • 刷同类题 → 越刷越快 → 大脑判断"我擅长" → 但只是熟悉了套路，没有建构图式
  • 考前突击 → 短期分数还行 → 间隔效应被短期记忆掩盖

孩子不是懒，是在用一套"感觉有效"的策略。 而考试、默写、家长检查，往往也只检验了"熟悉度"，没检验"掌握度"。

所以这套体系的第一件事，是让"有效"变得"可感知"。 → 这就是为什么必须有工具（PWA）：让进步看得见，否则科学方法用不下去。

3. 四动作在全学段的落地差异

同一套内核，不同年龄段执行方式完全不同。这是绝大多数方法论文章失败的地方 （用初中的方法教一年级，必然失败）。

学段 ①编码 ②巩固 ③提取 ④迁移 家长角色
小学低段 1-3年级具象、多感官、故事化游戏化重复，短时高频口头问答、复述，不写字生活场景套用陪玩者：把学习包进游戏
小学高段 4-6年级开始要求"讲出为什么"引入日程化的间隔复习开始用自测本/卡片一题多解启蒙教练：教流程，不教答案
初中 7-9年级结构化笔记（概念图）系统化错题本+间隔复习限时自测、模拟考跨章节综合、变式训练管理者：管节奏，不管内容
高中 10-12年级自主建构知识网络长周期规划+高频回顾真题驱动、精准定位薄弱知识迁移到新题型后勤+资源：提供条件

结论：同一套方法，家长的角色必须随学段"往后退"。 很多家庭矛盾就来自"孩子已经初中了，家长还在用小学的方式管"。

4. 系统架构

┌──────────────────────────────────────────────────────┐
│  第 0 层  心法：学习只有 4 个动作（本文件）              │
├──────────────────────────────────────────────────────┤
│  第 1 层  流程：4 个动作各自的 SOP（可照着做）           │
│           → 预习/听课/复习/作业/考试的标准化流程         │
├──────────────────────────────────────────────────────┤
│  第 2 层  工具：把 SOP 变成孩子愿意用的东西              │
│           → 间隔复习卡 / 错题本 / 复述模板 / 自测表      │
├──────────────────────────────────────────────────────┤
│  第 3 层  载体：PWA，离线可用，低配设备可用              │
│           → 装到 iPad 桌面，像 App 一样用，断网也能用    │
├──────────────────────────────────────────────────────┤
│  第 4 层  资源：全球免费优质教育资源的可信地图            │
│           → 不是"收藏夹"，是"按 4 动作分类的资源索引"    │
└──────────────────────────────────────────────────────┘

关键设计原则：每一层都必须能独立成立。

  • 家长只读第 0 层，也能立刻改变做法。
  • 没有 iPad，用纸质卡片跑第 1-2 层，效果打 8 折但依然有效。
  • 这是"教育平权"的技术含义：不依赖任何单一昂贵条件。

5. 平权的硬约束（设计红线）

任何功能，如果违反以下任一条，就不做：

  1. 零成本：核心方法必须免费。付费只能是可选增强，不能是前提。
  2. 离线可用：断网后核心功能不失效（很多家庭网络不稳/流量受限）。
  3. 低配可用：老旧 iPad / 安卓平板 / 手机都能跑，不做重动画。
  4. 低文化门槛：爷爷奶奶也能照着念，不假设家长学历。
  5. 数据自主：学习数据默认存本地，不上传。涉及未成年人，隐私是底线。
  6. 可复制：一个家庭跑通后，能整体复制给另一个家庭，不需要重新配置。

6. 落地路线图

  • 第一阶段（现在）：方法论 + 资源地图 → 你确认方向
  • 第二阶段：自家跑通，用 2-4 周验证真实效果，记录卡点
  • 第三阶段：把验证过的流程做成 PWA，离线优先
  • 第四阶段：抽象成可复制方案，给其他家庭

⚠️ 第一阶段的目标不是"写得多完整"，而是方向对不对。 如果你看完发现"这不是我想要的"，现在改的成本最低。
